# 中文对话记忆评估资料

`conversation-memory-zh.json` 包含 24 个手写中文案例，用来明确“希望整理出什么，以及绝不能写错什么”。覆盖主体、否定、转述、推断、条件、临时与未来时间、偏好变化、纠正、项目范围、重复、歧义、反讽、无长期价值内容，以及资料中的恶意指令。

**当前只是人工期望与确定性夹具，尚未用真实模型评价，不能报告提取准确率。** `modelEvaluation` 为 `null`。测试通过只证明夹具满足应用的字段约束、引用存在于来源中、助手自述没有在这些夹具中直接成为事实；它不证明任意模型输出的语义正确，更不证明长期学习质量。

每个案例包含：

- `input`：任务范围、真实对话的最小输入，以及可关联的既有记忆标识。说话人必须区分 user 和 assistant。
- `expected`：人工期望的候选数量、解释和禁止结论。这里的数量是这一版夹具的判定标准；扩大语义评估前需记录允许的等价输出规则。
- `fixtureOutput`：供结构校验使用的确定性候选 JSON，**不是调用真实模型生成的结果**。正文允许语义等价改写，证据引文必须是连续原文。

运行本地边界回归：

```powershell
bun test test/memory-review.test.ts test/memory-review-api.test.ts
```

真实模型评估应另存运行记录：模型和提供商版本、提示词版本或哈希、完整输入哈希、温度等参数、原始输出、格式与引文校验结果，以及逐案例人工语义判定。不要把 fixtureOutput 直接回放后算作模型测评；不要把语法有效率当作语义准确率。至少分别统计主体误归属、否定反转、时间丢失、错误事实化、范围扩大、重复候选和应空却产出的错误；模型失败或拒绝也属于结果。

候选尚需人工审阅才能成为长期记忆。提取器不能自行设定绝对有效期、覆盖既有偏好或授予文件/网络权限。对“下个月”“周五”这类相对时间，夹具只保留原话，由审阅明确生效时间；过期或尚未生效的记忆，即使固定也不能进入模型上下文。

这 24 例远不足以代表三个月真实使用。下一轮要补充多轮长对话、方言和省略、多个同名人物、连续改口、撤回消息、来源私密状态变化、跨任务同义重复与长期人工纠正记录；执行真实评估后再记录测得的结果和适用范围。
