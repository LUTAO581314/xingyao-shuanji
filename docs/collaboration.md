# 子智能体协作视图

`0.1.0-dev.10` 增加只读的「协作」入口。它把一个星杳任务绑定的 OpenCode 根会话作为信任边界，通过公开 HTTP 接口读取后代会话、当前状态和消息历史，让主人检查分工、进度、结论与来源。

## 责任边界

- OpenCode 负责创建、运行和保存子会话。星杳当前不通过这个页面创建、恢复、重试或修改子智能体。
- 星杳主任务负责汇总结论、核对成果和交付。子会话显示 `completed` 或某个工具返回成功，不等于主任务完成。
- 子智能体消息保持独立来源，不自动写入主任务聊天、记忆、经历或技能证据。
- 原始会话历史由 OpenCode 数据库和配套检查点保存。协作页是有界投影，不建立第二份完整转录。
- GitHub 聊天档案与产品内 OpenCode 会话是两条数据通道。当前 GitHub 导出不会因为协作页可见而自动包含引擎内部子会话。

## 读取协议

适配器只使用 OpenCode 公共接口：

```text
GET /session/:sessionID/children
GET /session/status
GET /session/:sessionID/message
```

遍历从产品任务持久化的根 `sessionId` 开始。每个子会话必须声明预期的 `parentID`；重复 ID、循环、跨会话消息、重复消息 ID、非法时间和未知状态都会使整次读取失败。接口不接受浏览器提供任意根会话 ID，因此另一个任务不能借查询参数读取不属于它的树。

当前限制为 32 个子会话、4 层、单个历史响应 1 MiB、页面正文投影合计 2 MiB、整次读取 15 秒。达到会话数、深度或正文预算时页面明确显示截断。正文预算优先保留已遍历会话中的较新消息；页面不是完整导出接口。

## 浏览器投影

消息正文保留会话、消息和部件来源 ID。工具只向浏览器发送：

- 工具名、调用 ID 和来源 ID；
- 生命周期与经过适配器核验的结果类型；
- 可验证时的退出码和起止时间。

工具输入、原始输出、任意上游错误详情、状态扩展字段和认证元数据不会进入协作响应。页面用 DOM `textContent` 渲染会话标题、角色和正文，不把上游文本解释为 HTML。

## 更新兼容

引擎健康检查会单独报告 `collaboration` 能力。核心对话兼容仍由 legacy HTTP、完整消息历史和 `system` 字段决定；上游暂时缺少协作路由时，主工作流仍可运行，协作页显示读取失败。每次升级必须用固定候选引擎创建真实父子会话并通过适配器测试，不能只依赖 OpenAPI 路由存在。

当前实现验证了 engine.6-source 的真实根会话、直接子会话、空历史和 idle 状态。包含模型生成消息与工具调用的完整浏览器场景由发行门禁继续覆盖。
