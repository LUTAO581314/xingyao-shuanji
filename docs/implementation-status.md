# V2 实施与验收状态

本记录区分已经实现的能力与完整架构中的后续工作，不将设计稿当作已实现功能。

## 已实现，验收结果绑定具体发行制品

- 独立 Bun/SQLite 领域运行时；稳定身份；根来源幂等；情绪/心境闭式传播。
- 事实、偏好、推论、承诺、情节的范围与来源；纠正、封存、删除及同源删除标记。
- 记忆检索按词项相关度和新鲜度评分；新鲜度采用 14 天半衰期，固定记忆保留。该衰减不等于自动删除源记录。
- 前台任务、唯一 OpenCode 执行路径、权限响应、实际工具结果对账、unknown 恢复。
- 手动与运行期间空闲睡眠；处理游标与归档同事务，封存策略遵循事件进入时状态。
- 中文资料检索、引用位置、增量更新、文件整理后的稳定资料引用。
- `0.1.0-dev.3` 新增本地 Cytoscape 知识图谱、已导入资料目录树、名称与类型筛选、已加载邻居浏览、来源正文分页和记忆/经历详情。范围和私密标记先在查询中过滤，文档版本变化后要求刷新图谱；具体发行验收记录另行绑定制品。
- `0.1.0-dev.4` 调整图谱布局的初始位置、节点间距与标签尺寸参与方式，减少切换筛选后的节点重叠；窗口缩放后自动适配视图。
- 经验候选、独立调用计数、有限证据预测、人工启用、证据撤回重审。
- 浏览器工作台；回环绑定、随机令牌、Origin 与 Host 校验、CSP。
- 文件整理清单、目标冲突检测、原件保全、撤销与断点恢复。
- NTFS 活动库、U 盘完整代次、引擎配套数据库、单写者锁、分叉检测。
- 领域库与引擎数据库的配套恢复日志；先验证两者，再保全旧数据、安装和接续中断的恢复。
- Windows 稳定工作路径、独立编译入口、发行哈希校验、验收门禁、历史选择日志。

## 完整设计中的待推进项

- 可审阅的模型记忆提取与人物/关系/世界认识，先通过中文真实语料的归属和事实评估。
- 真正的项目文件浏览与编辑、全库图谱查询与大图性能、子智能体协作面板、独立 Infinite Canvas 视觉创作模块；当前图谱目录树仅覆盖已导入且本次已加载的资料。
- 候选整理与学习收益的 20–30 个真实任务对照集，情绪表达和恢复参数的使用体验校准。
- 模型技能提案、小范围评估、有界长期气质成长；当前仍采用固定气质和人工候选。
- 自动记忆压缩、归档与历史备份清理策略；目前显式删除不删除已有检查点、原生 OpenCode 会话或原始文件。
- 恢复分支与回滚的图形化选择、跨机版本迁移向导，以及删除旧备份的明确保留策略。
- 用户原生 OpenCode 会话的隐私删除/重建流程；目前独立记忆删除不修改原生会话。
- 原始资料、OpenCode 附件和项目依赖的全量可选迁移与离线可用性清单。
- PDF/OCR、语义索引、语音、视觉、Linux 启动模块、便携凭据加密。
- 大库与慢 U 盘性能测量、实际拔盘/断电故障试验、容量限额与缓存回收自动执行。
- Docker 沙盒按需执行集成；当前运行方式为 Windows 本机工作台与受权限约束的 OpenCode。

## 验收依据

测试分别覆盖领域不变量、真实 SQLite/WAL/锁、实际文件系统、实际浏览器、真实 OpenCode HTTP+工具执行，以及编译后的 Windows 主程序。真实模型服务在验收中由本地确定性 HTTP 夹具替代，不使用公网密钥；这验证协议与执行链路，不证明真实模型生成质量。

最终计数、制品哈希、版本及安装位置写入对应发行的 `release-validation.json` 与 `docs/verification.md`。任何跳过的真实后端测试不得计为发行通过。
